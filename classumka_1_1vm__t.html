Detailed Description

An Umka interpreter and everything loaded into it.

Owns the interpreter for its lifetime. Neither copyable nor movable.

umka::vm_t vm{"script.um", 1024 * 1024};
auto add = vm.function(umka::main_module, "add");
auto n = add.call<umka::int_t>(40, 2);

inline

Allocate, initialise, register, compile and run.

Performs the whole start-up sequence in the only order that works: every extern function and module source is registered before compilation, then main() is run.

Parameters
scriptPath to the main script.
stack_sizeStack size in slots, not bytes; 2 * 1024 * 1024 is 16 MiB.
modulesNative modules to bind.
See also
umka::module_t
Note
Terminates on allocation failure, an init error, a rejected function or module, a compile error, or a runtime error in main().
