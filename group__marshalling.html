export

Write one argument into a parameter slot.

Accepts scalars and enums, raw pointers, umka::str_t (converted with umkaMakeStr), umka::arr_t, umka::borrowed_t, and trivially copyable mirror structs. Standard-library containers are rejected at compile time by design.

Template Parameters
TDeduced argument type.
Parameters
interpreterThe interpreter, needed to convert strings.
paramsA parameter buffer from a context filled in by umkaGetFunc; it carries the stack frame layout umkaGetParam needs.
indexZero-based parameter index.
valueThe argument. Taken by value, so arrays and string literals have already decayed to pointers.
