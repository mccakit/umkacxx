◆ instance()

auto umka::instance ( slot_t * result) -> interpreter_handle_t
nodiscardexportnoexcept

Recover the interpreter inside an extern function.

An extern function is handed no interpreter; result->ptrVal carries it on entry.

Parameters
resultThe result slot, exactly as received.
Returns
The interpreter that made the call.
Warning
Call this before writing anything into result. Writing overwrites the handle.

Template Parameters

Parameters
