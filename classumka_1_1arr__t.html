Detailed Description

template<typename T>
class umka::arr_t< T >

A view over an Umka dynamic array.

Layout-compatible with UmkaDynArray(T): {type, itemsize, data}. Slots are memcpy'd straight in and out of this, so the member order and the absence of any extra state are load-bearing — in particular the type cannot hold an interpreter pointer, which is why reference counting goes through umka::vm_t::decref rather than a member function.

This is a view, not an owner. It never allocates and never releases.

Template Parameters
TThe C++ mirror of the Umka item type. It must match the Umka item layout exactly; this is only verified for arrays built by umka::make_arr.
